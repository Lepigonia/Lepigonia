## Setup
This is a Next.js 14 markdown blog. 100% free hosting via Vercel.

### How to deploy (2 min)
1. Push this folder to GitHub repo `Lepigonia/lepigonia-blog`
2. Go to vercel.com -> Add New Project -> Import `lepigonia-blog`
3. Deploy -> you get lepigonia-blog.vercel.app live
4. In Vercel Settings -> Domains -> add your custom domain later if you want
